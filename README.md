# 前言

欢迎来到基于SSM（Spring、SpringMVC、MyBatis）的校园二手系统项目，该项目旨在为在校大学生提供一个便捷、高效的二手物品交易平台。本项目完全开源，并提供详细的文档和源码，供广大开发者学习和交流。

# 内容介绍

基于SSM的校园二手系统主要包括以下几个模块：用户模块、商品模块、订单模块、消息模块等。用户可以通过发布商品、浏览商品、下单购买等操作，实现校园内二手物品的买卖。此外，系统还提供消息通知功能，以便用户及时了解商品动态。

# 技术介绍

## 语言：Java

## 使用框架：Spring、SpringMVC、MyBatis

## 前端技术：JS、Vue、CSS3

## 开发工具：IDEA/Eclipse

## 数据库：MySQL 5.7/8.0

## 数据库管理工具：phpstudy/Navicat

## JDK版本：jdk1.8

## Maven：apache-maven 3.8.1-bin

## 前端环境：Node.Js 12、14、16

# 核心代码

以下是项目中一个简单的示例代码，展示如何通过MyBatis实现用户查询操作：

```java
// UserMapper.xml
<select id="selectUserById" resultType="com.example.entity.User">
    SELECT * FROM user WHERE id = #{id}
</select>

// UserService.java
public User getUserById(int id) {
    return userMapper.selectUserById(id);
}
```
